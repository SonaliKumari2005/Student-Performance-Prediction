# Student-Performance-Prediction
Student Performance Prediction System using Machine Learning and Streamlit. Predicts student final marks based on study hours, attendance, previous marks, and assignments completed. Includes performance analysis, model accuracy, and prediction visualization.
# 🎓 Student Performance Prediction System

## Overview

This project predicts student final marks using Machine Learning and Streamlit.

## Features

* Predict student marks
* Performance classification
* Model accuracy display
* Interactive graph visualization
* Prediction point highlighted on graph

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Streamlit

## Input Features

* Study Hours
* Attendance
* Previous Marks
* Assignments Completed

## Output

* Predicted Marks
* Performance Category
* Graph Visualization
